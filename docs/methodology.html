What "checked" means

Every skill here was checked to make sure it isn't malicious before it was listed. That is the whole promise, so here is exactly what the check is — and what it isn't.

What the check is

  • Before a repo is listed, an automated scanner clones it and reads every file for known-dangerous patterns: install lines that pipe a download straight into a shell, code that reads credentials or SSH keys, hooks that run on every session start, and obfuscated or encoded blobs hiding what the code does.
  • Anything flagged is quarantined — pulled out and never listed, not listed with a warning. Only a human who has read the flagged lines can restore it.
  • The catalog only admits repos that are real, carry an open-source license, were pushed to in the last year, and actually contain a skill.
  • The date of each repo's scan is in the catalog data (checked.date), which is public, so you can see when it was checked.

What the check is not

  • Not an endorsement. Listed means "we found nothing malicious," not "this is good" or "this will work for you."
  • Not a guarantee. A pattern scan catches obvious malice, not clever malice. Code can also change after we scan it — that's why the Skillproof skill re-reads the current source at install time, before it runs anything.
  • Not a warranty. Everything here is provided as-is. Read anything before you run it.

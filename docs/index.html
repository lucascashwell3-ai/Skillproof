Paste-in advisor prompt

For Claude in the browser or app — nothing to install. Paste it once and that chat becomes your skill advisor: describe a problem, it answers from this catalog and scouts honestly beyond it. Short on purpose — it reads the live catalog itself, so it never goes stale.

Download the catalog

If your agent can’t browse the web, download the catalog and attach it to the chat instead.

The scout skill

For Claude Code. Fires on "find me a skill for…" — checks this catalog first, then searches the live ecosystem and returns a shortlist with provenance, license, freshness, and safety flags on every candidate.

mkdir -p ~/.claude/skills/skillproof-scout && curl -fsSL https://raw.githubusercontent.com/lucascashwell3-ai/Skillproof/main/skills/skillproof-scout/SKILL.md -o ~/.claude/skills/skillproof-scout/SKILL.md

Read what you're installing first — we'd grade us too: SKILL.md ↗

MCP server

For Cursor, Claude Desktop, and any other MCP-capable agent. The catalog as four read-only tools your agent can query mid-task — same data file this page renders.

git clone https://github.com/lucascashwell3-ai/Skillproof && cd Skillproof/mcp && npm install
claude mcp add skillproof -- node /path/to/Skillproof/mcp/server.js

Your pain points are the filter. Everything else follows from them.

No leaderboard, no crawl through a thousand-item marketplace. Just: this is what's slowing me down, so this is what's worth adding.

01

Describe the problem

Where you run AI, plus up to three pain points — generic frontend output, tests that get gamed, sessions that lose the plot. A few taps, then the rail folds into a one-line summary you can reopen anytime.

02

Read the reasons, not a rank

Every row carries plain-English reasons tied to what you tapped: targets your pain point, tested by us with receipts, or scouted-only with its real red flags shown — a missing license, a quiet repo — never hidden.

03

Assemble and install

Drop picks in the tray. It flags overlaps between them, then writes one install plan: real commands for tested entries, review-first links for scouted ones. Copy it, paste it, done.

Checked before it lists

Quality is the bar for entry, not the product. Every entry is verified against its real source before it shows up here — and labeled by exactly how far that check went. The full protocol is published.

Tested & graded

Installed, probed in real sessions, source read line-by-line. Each grade links to the worksheet that produced it — the receipts.

Scouted, ungraded

Found and triaged: repo verified real, license and freshness checked, safety skimmed. Never installed, never probed — and it says so on the row.

Never faked

An automated honesty gate blocks any entry that claims more than its receipts support. No placeholder grades, no invented stats, ever.

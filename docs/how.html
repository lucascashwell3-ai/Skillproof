Checked before it's cataloged

Every entry is verified against its real source, with two levels of verification.

Tested

  1. Installed into a clean project
  2. Probed in real sessions — does it fire when it should, do what it claims?
  3. Every line of its source read before anything ran

Scouted

  1. Repo verified real — author, stars, created-when, license, freshness
  2. Source code screened for known malicious patterns; anything flagged is read by a person before it can list
  3. Not yet run by us ourselves — that's what the Tested tier means

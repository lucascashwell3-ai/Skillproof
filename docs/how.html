If it's listed, its code was read

One promise instead of a tier system. Every skill on the site had its full source read at the exact version you'd install — so you don't have to think about it.

How a skill gets listed

  1. Found and screened — anything flagged as malicious is quarantined and never listed
  2. Full source read at its current version: what it does, what it touches, how to undo it
  3. Listed — the read is pinned to the exact code it covered

How it stays honest

  1. When a skill's upstream code changes, its old read no longer counts
  2. It quietly leaves the list until the source is read again at the new version
  3. A nightly reader re-reads changed skills, so the list heals on its own
